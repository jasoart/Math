# 540 組模組學院

入口：[模組學院](https://jasoart.github.io/Math/academy.html)。

新增 **540 組可操作情境**，以 **45 個核心數學模型各 12 組不同參數**建立；分為 9 個主題，每個主題 60 組。這些是獨立編號、可調參數、可保存／分享的情境模組，不宣稱有 540 種獨立演算法。原有 196 個探索實驗另行保留，全站搜尋共 736 個入口。

## 操作方式

1. 依主題、模型或關鍵字篩選，每頁最多 12 筆；也可只看收藏、尚未完成與待複習情境。
2. 每組包含具體題目與參數，調整後立即重新產生圖形、問題與推導；「比較」會疊上此組初始參數的灰色圖形。
3. 自行作答，可用小數、分數、根號；一般結果採相對／絕對容差 1e-5，二項、超幾何與貝氏機率採相對容差，以免極小正機率被 0 取代。一次有效作答計入一次；變更參數或重新開始可再答，重試會計入正確率。
4. 答對會把此情境標記完成；答錯列入待複習，之後答對清除待複習標記。展開教練區可閱讀數學訊號、各步原因與公式、快捷思路及常見陷阱。
5. 「下一組變體」循環開啟同一核心模型的 12 組情境。「恢復」回到目前編號的預設參數。
6. 「送入 MathScript」帶入目前所有參數、計算步驟和圖形；可進一步編輯、執行與發布結果快照。
7. 分享連結含模組 ID 及目前參數；可下載 .mathscript、數值表 CSV 與包含推導的離線 HTML。

圖形使用有限取樣；兩軸比例可能不同，長度與角度以公式計算為準。離散數列及機率使用 scatter，另附數值表。本內容是觀念與延伸學習素材，不是官方歷屆題庫或課綱認證。

## 資料與效能

- 固定 ID：academy-模型名稱-01 至 12。預設參數用固定種子建立，模型內 12 組參數不重複。
- 所有預設與輸入皆經範圍、步長及未知欄位檢查；計算與 MathScript 匯出使用同一份模型定義。
- 收藏、作答與最近狀態保存在 mathlab.academy.v1，與既有筆記／練習分開。支援同源分頁的 storage 事件同步。
- 備份格式 kind=mathlab-academy、version=1；最多 540 個紀錄、每情境最多 100,000 次作答、匯入最多 300 KB。完整驗證成功後才套用，錯誤備份不破壞當前紀錄。
- 原有本機紀錄無法解析時，暫停自動覆寫，可先匯出本次資料，再匯入有效備份恢復儲存。瀏覽器拒絕儲存時明確提示。
- 列表分頁避免一次建立 540 個卡片 DOM；只計算當前模型，滑桿使用 80 ms 合併更新。既有 196 個主探索模組的載入流程不增加模型運算。
- 全部資源隨站提供，PWA 安裝完成後可離線開啟模組與 MathScript。

## 維護與驗算

模型：academy/models.js；紀錄與分享格式：academy/state.js；互動介面：academy/academy.js。

執行 npm run test:academy：以 Python 的 Fraction、座標距離、Gram 行列式、鞋帶面積、組合數、Gaussian 消去、迭代總和及 Simpson 數值積分獨立核對 **914 組**預設／邊界結果，包含全部 540 預設。另驗證每組來源程式可執行、有限圖形資料、ID／參數唯一性、備份和連結驗證；DOM 流程覆蓋篩選、分頁、調參、比較、作答、錯題、分享與匯出。

修改模型或入口後依序執行 npm run build:catalog 與 npm run build:pwa。DOM／VM 測試不代表真實瀏覽器的排版、觸控、Worker 或 Service Worker 已實機驗證。
