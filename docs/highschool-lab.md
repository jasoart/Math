# 高中探究與平面繪圖升級

- 互動探索共 **520 個**：保留原本 196 個，加上 36 類 × 9 個，共 324 個新探究實驗。
- 模組學院仍有 540 組情境；全站搜尋共 1,060 個入口。
- 新增實驗有独立穩定 ID、不同算式、教學提示、參數、收藏、筆記與分享；同類實驗共用運算與繪圖引擎，**不是 324 種獨立演算法**。
- `.msw` 為維護來源，詳見 [MathScript Web](mathscript-web.md)。

## 36 類實驗

直線、二次根、頂點式、三次函數、四次函數、根的重數、約分破洞、鉛直漸近線、遠方行為、有理式定義域、絕對值、距離和、根號端點、根式運算、立方根、指數、對數、正弦、餘弦、正切及倒三角比、三角恆等式、波與包絡、反三角函數、分段連續、跳躍與點值、階梯函數、反關係、複合函數、圓、橢圓、拋物線、雙曲線、參數圓與橢圓、李沙育、參數軌跡、極座標。

新實驗的「送至平面繪圖」保留目前 a、h、k 與算式限制。函數使用縱向尺度，幾何圖形使用等比例尺度；參數軌跡顯示 t∈[0,2π]，其他區間可在平面繪圖調整。

## 10 種工具

| 工具 | 功能與界線 |
| --- | --- |
| 方程／不等式符號表 | 有限閉區間，分子、分母與原式禁點條件各不超過二次的有理式。單點與開區間分列，保留約分禁點；係數仍用浮點結構運算。 |
| 增減與極值 | 以可支援的導數符號表判定內部變號極值；不自動判定所有端點最值。 |
| 左右極限 | 8 層十倍縮距表；簡單有理式可得到結構性有限極限，其餘只提供數值趨勢。 |
| 割線／切線／法線 | 割線與自動微分；在無法確認有限導數時只給割線。法線以隱式避免倒數溢位。 |
| 平移／伸縮 | 產生 a·f(x−h)+k；自訂範圍限制暫不搬移。 |
| 反關係 | 交換 x、y 並畫 y=x；不宣稱任何反關係都是函數。 |
| 圓切線 | 圓內、圓上、圓外三種情況與垂直條件核對；近圓周精度模糊時拒絕判斷。 |
| 三角形三心 | 外心、重心、垂心、外接圓與邊；近共線情況拒絕作圖。 |
| 線性迴歸 | 2–100 筆，中心化最小平方法、SSE、R²、逐筆殘差。所有 y 相同時 R² 未定義；只把前 10 點加入畫布。 |
| 黎曼和 | 1–100 等分，四種方法，正負面積積木；參考積分仍是數值近似。 |

每次輸入或函數變動都會使舊結果失效。可下載 CSV，或保存包含條件、數值表、圖形的 HTML 報告。新增圖形仍受 12 列上限保護；使用者可明確選擇取代，目前內容可復原。

已辨識的有理式破洞以空心點標記，鉛直／水平／斜漸近線以虛線繪出。這不是完整 CAS；高階、多重根、近重根、三角奇點、自訂範圍的端點等可能未被辨識。導線與面積積木會加入 PNG／SVG；積木是暫存疊圖，不放入 JSON 或分享連結。

## 測試

`npm run test:highschool` 驗證所有新增實驗的初值及單一參數邊界、幾何不變量、BigInt 行列式參考、迴歸正交條件、黎曼和封閉式、定義域與奇異點。DOM 測試涵蓋畫布加入／取代／復原、結果失效、CSV／HTML、導線與 SVG、編譯編輯器。測試不使用 Python；沒有以 DOM 模擬宣稱已完成實機排版與觸控測試。
