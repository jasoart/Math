# 3D 需求對照

這份文件對照使用者提供的空間幾何／互動教學清單，記錄實作範圍；不是正式考試範圍或完整題庫的聲明。

| 功能 | 目前實作 | 後續範圍 |
| --- | --- | --- |
| 輸入與場景 | 模板、結構解析、多物件、文字條件先核對、場景分享與備份 | 題目截圖 OCR、圖題語意辨識 |
| 點線面與球面 | 點、向量、兩點直線、三點平面、任意平面、完整球面 | 約束拖曳、動畫建構 |
| 向量與量測 | 內外積、加減、投影、中點、距離、夾角、公垂線、交點／交線、三平面聯立 | 分點比例、一般多曲面交線 |
| 多面體與截面 | 三角錐、長方體、平行六面體、體積、座標截平面、多面體截面；任意平面物件可與球／多面體求交 | 展開圖、表面最短路徑 |
| 函數與參數 | 顯式曲面、隱式等值面、參數曲線／曲面、圓柱、雙圓錐 | 圓錐截面分類與曲面面積教學 |
| 積分實體 | 圓盤／圓環旋轉體、x／y 軸、截面積、精確可判定的 π 值及數值誤差 | 任意平移旋轉軸、柱殼法與切片和動畫 |
| 教學與練習 | 觀念、公式、推導、提醒、輔助物件、探索模式、數值答案檢查 | 手寫列式／理由批改、正式題庫／官方配分對應、跨裝置進度 |
| App 工作流程 | 安裝、離線、更新通知、底部抽屜、分享、復原、JSON 備份 | 原生 App Store 打包與雲端同步 |

正式題目與來源應逐項核對才填入，不能將生成例題或延伸曲面標成官方考題。靜態 GitHub Pages 不內嵌 API 憑證；影像辨識或雲端同步需另接適當的服務。
