# 課綱、歷屆試題與研究依據

資料截至 2026-10-09（臺北時間）。

- [來源與核驗限制](SOURCES.md)：原作者論文、公司研究文件、作者任職背景與官方入口狀態。
- [學測數 A 分析](EXAMS_MATH_A.md)：五卷共 100 個編號題。
- [分科數甲分析](EXAMS_MATH_ADVANCED.md)：五卷共 85 個編號題。
- `curriculum.json`：教學主題分類基線；內部 ID 不是官方課綱編碼。
- `sources.json`：網站呈現的原始來源資料。
- `exams-math-a.json`、`exams-math-advanced.json`：逐題主題、頁碼、配分、模組關聯及抽取不確定性。

原始資料保留 `proposedModuleIds`，記錄分析時提出的補強需求。v2.0 已實作其中引用的模組；`npm run evidence` 會核對所有 ID，並在生成的 `evidence.js` 中轉為 `extensionModuleIds`。模型與原題的關聯仍遵循逐題 `coverage` 限制，並非重現整題。

題號統計每個編號算一次，主分類互斥、次要主題可複選。統計不能推論命題機率、難度或答對率。分析保留 PDF 符號缺失與未逐頁看圖的限制；沒有猜測官方答案。

教育部、國教院與大考中心入口仍受目前網路政策阻擋，最新正式課綱正文、修訂日及各卷官方版本尚未核驗。原站與論文全文所需網域已加入環境設定草稿；設定生效後應重新讀取並更新此處狀態。
