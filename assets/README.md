# Website artwork

The geometric hero and transparent sculptural icon were generated with the built-in image generation tool for this website on 2026-10-11, at the repository owner's request. They are original generated artwork, not external project logos or mathematically exact surface plots.

- `studio-hero.webp`: desktop artwork, 1536 × 1024.
- `studio-hero-mobile.webp`: same artwork encoded at 900 × 600 for smaller displays.
- `studio-icon.webp`: transparent navigation icon, 192 × 192.
- `studio-icon.png`: transparent favicon and web manifest icon, 192 × 192.

The generated PNG sources were resized and encoded for web delivery; no remote image service is needed at runtime. The hero uses responsive sources and explicit dimensions to reduce transfer size and layout shift. Brand text and navigation are accessible HTML, separate from the artwork.
