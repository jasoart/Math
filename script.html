    SMALL LANGUAGE. ROOM TO EXPLORE.

    從一個想法開始。

    名稱可用中英文，區分大小寫。先定義，再使用。三角函數使用弧度；π 可寫成 pi。

    完整語言規格與範例 ↗

    01 / 定義

    參數 a = 1 從 -3 到 3 每 0.1
    函數 f(x) = a * x^2

    02 / 看見

    視窗 -6, 6, -4, 8
    繪圖 f(x) 標籤 "我的曲線"

    03 / 驗證

    顯示 f(2)
    積分 f(x) 從 0 到 2
    更多指令
    let / 設
    let radius = 2
    curve / 曲線
    curve (cos(t), sin(t)) from 0 to 2*pi
    point / 點
    point (1, 2) label "A"
    table / 表格
    table x^2 from -2 to 2 step 1
    roots / 求根
    roots x^2-2 from -3 to 3
    if / 條件函數
    plot if(x < 0, -x, x^2)
